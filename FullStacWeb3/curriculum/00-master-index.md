
# StudyLend Master Curriculum

The project is now a four-discipline curriculum.

## HTML
`01-html.md`

Study the web platform and semantic document layer:
structure, media, forms, accessibility, SVG, canvas, metadata, security,
performance, Web Components and progressive enhancement.

## CSS
`02-css.md`

Study the complete styling/layout layer:
selectors, cascade, box model, Flexbox, Grid, responsive design, container
queries, animations, accessibility, architecture, modern CSS and performance.

## JavaScript
`03-javascript.md`

Study the programming/runtime layer:
language fundamentals, DOM, browser APIs, asynchronous programming, modules,
security, Web3, contract interaction, testing, TypeScript and performance.

## Solidity + Foundry
`04-solidity-foundry.md`

Study:
Solidity → EVM → standards → DeFi → security → testing → deployment →
protocol architecture.

## The rule

When a topic is not used by the current protocol, **do not remove it**.

Instead:

```text
ACTIVE IMPLEMENTATION
        +
COMMENTED LEGACY PATTERN
        +
COMMENTED ALTERNATIVE PATTERN
        +
PRODUCTION NOTE
```

That makes this repository both:

1. a runnable DeFi application, and
2. a long-term curriculum/reference project.
